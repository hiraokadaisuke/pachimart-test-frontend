# 簡単見積り 拡張機能プロトタイプ

## 確認URL

`/estimate/demo`

## 目的

既存の簡単見積りデータを使い回し、次の3操作へ進むUIと操作の流れを確認するためのフロントエンドデモです。

- 見積りを相手に送信
- 選択機種を一括掲載
- 選択機種から一括で取引ナビを作成

## 他機能への影響を避ける構成

- 既存の `/estimate` は変更していません。
- 新しい `/estimate/demo` だけを追加しています。
- API、DB、メール、通知、商品掲載、取引ナビには接続していません。
- 入力内容は専用の `localStorage` キーだけに保存します。
- 他画面のコンポーネントや状態は変更していません。

## デモで確認できること

1. 見積り表で対象機種をチェックする。
2. 「見積りを送信」「一括掲載」「一括ナビ作成」のいずれかを選ぶ。
3. 3ステップのモーダルで、対象確認、条件設定、最終確認を行う。
4. 確定時にデモ完了メッセージを表示する。

未選択の場合は、入力済みの全機種を対象にします。

## 正式実装時の主な接続候補

- 会社・担当者・倉庫の検索API
- 見積り送信、パチマート内通知、メール通知
- 相手側の行単位回答（承諾・見送り・価格相談）
- 商品掲載の下書き一括作成
- 取引ナビの複数明細一括作成
- 権限、二重送信防止、必須項目、監査ログ

正式実装では、見積り一覧に掲載・ナビ専用項目をすべて増やすのではなく、各操作を選択した後のモーダルで不足項目を補う構成を想定しています。
